# Grove v0.2.0-beta1

v0.2.0-beta1 promotes the Grove APIs to beta. It adds `grove.io/v1beta1` and `operator.config.grove.io/v1beta1`
and makes `grove.io/v1beta1` the version that Grove stores. The new versions behave the same as `v1alpha1`; they
only drop fields that Grove no longer uses. Read [Upgrading to v0.2.0-beta1](../user-guide/upgrading-to-v1beta1-v0.2.0-beta1.md)
before upgrading.

## API changes

- **`grove.io/v1beta1`** is served and stored for PodCliqueSet, PodClique, PodCliqueScalingGroup,
  ClusterTopologyBinding and PodGangMap. The operator reads and writes only `grove.io/v1beta1`.
- **`grove.io/v1alpha1`** is still served and deprecated. The API server returns a deprecation warning for every
  `v1alpha1` request, and converts PodCliqueSets between the versions through the operator's conversion webhook.
- **`topologyConstraint.packDomain`** is removed from `grove.io/v1beta1`. Use `topologyConstraint.pack.required`.
  A `packDomain` stored by an earlier release is converted to `pack.required`.
- **`PodCliqueSetStatus.podGangStatuses`** is removed from both versions. Grove never set it.
- **`operator.config.grove.io/v1beta1`** is the operator configuration version that the Helm chart renders. The
  operator still accepts `operator.config.grove.io/v1alpha1` and logs a deprecation warning.
- **PodGang** stays at `scheduler.grove.io/v1alpha1`.
- The Go packages drop the unused `LastOperation`, `LastOperationType`, `LastOperationState` and `PodGangPhase`
  types, and `v1alpha1.Kind()`, from `grove.io`, and `KaiSchedulerConfiguration` from
  `operator.config.grove.io/v1beta1`.

## Upgrade and downgrade

- When the operator starts, it rewrites every Grove object so that it is stored as `grove.io/v1beta1`, and then
  sets `status.storedVersions` of each CRD to `["v1beta1"]`. The rewrite changes no spec, so no Pod is recreated.
  The `grove_storage_migration_*` metrics report its progress.
- `grove-install-crds prepare-downgrade` moves the objects back to `grove.io/v1alpha1` and removes
  `grove.io/v1beta1` from the CRDs, so that a Helm rollback to v0.1.0-alpha.16 succeeds.
- CI runs an upgrade from the latest v0.1.x release and a downgrade back to it.

## Action required

- Upgrade from a v0.1.x release, and apply the v0.2.0-beta1 CRDs as part of the upgrade, for example with
  `crdInstaller.enabled=true`.
- Move your manifests to `grove.io/v1beta1`, and replace `packDomain` with `pack.required`. Re-applying a manifest
  that sets `packDomain` to an existing PodCliqueSet fails after the upgrade.
- If you provide your own operator configuration file, move it to `operator.config.grove.io/v1beta1`.
- If you use the Go API packages, move from `github.com/ai-dynamo/grove/operator/api/core/v1alpha1` to
  `github.com/ai-dynamo/grove/operator/api/core/v1beta1`, and from `config/v1alpha1.DecodeOperatorConfig` to
  `config.DecodeOperatorConfig`.
